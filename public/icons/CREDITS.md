# Créditos de los íconos

Los íconos de esta carpeta (y `src/app/icon.png` / `src/app/apple-icon.png`) son de
**Fluent Emoji** de Microsoft, estilo "3D":
https://github.com/microsoft/fluentui-emoji

Se redujeron de paleta para que pesen menos; el diseño no se modificó.

| Archivo | Emoji original |
| --- | --- |
| `campana.png` | Bell |
| `check.png` | Check mark button |
| `corriendo.png` | Person running (Default) |
| `reloj-arena.png` | Hourglass not done |
| `paquete.png` | Package |
| `prohibido.png` | Prohibited |
| `globo.png` | Speech balloon |
| `advertencia.png` | Warning |
